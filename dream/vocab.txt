# dream/vocab.txt —— LLM 书写 FR 的词汇速查（**:px 紧凑档**；真源 tables/cmd.tbl）
会话几何与资产目录单由系统消息给出；你只写 frame 块。规则：
1. 每块以 `frame N` 开头（N 从上一帧 +1 连续递增）；
2. 块内只写绘制行（短名）；dt/asset/ev/s_crc/d_crc 由 runner 书写，出现即拒绝；
3. 坐标/尺寸是整数时就写整数（100 而非 100.000000）；确有小数才写 %.6f；
   **角度一律弧度**（整圈=6.2832，90°=1.5708，30°=0.5236）；
4. 行序=深度：后写的行盖住先写的。全量帧固定顺序：clear 最先 → 背景行其次 →
   人物/物件再次 → 文字 print 最后；
5. 资产只引用目录单里的 id（fr-lint L001 拦截幻资产号）；
6. 运动=每帧重算坐标：抛物线 y=h-4t(T-t)、圆周 x=cx+r*cos(a) y=cy+r*sin(a)、
   帧动画=按 frame N 奇偶交替换图。三角函数值自己算好写进行里。

绘制行指令表（坐标系：原点在左上角，x 向右增大，y 向下增大；
mode: 0=填充 1=描边；所有颜色为 r g b a 四字节，255=不透明）：
  C  清屏为纯色：C <r> <g> <b> <a>                        ← 全量帧首行
  D  画位图精灵（图片）：D <tex> 0 <x> <y> <rot> <sx> <sy>
      图片左上角放在 (x,y)；rot=旋转弧度（顺时针）；sx sy=横纵缩放
      （负数=镜像翻转）；第 2 参 0=整图不裁剪；尾部 ox oy 色三段可省略
      （ox oy=旋转轴心偏移量，默认 0；色默认白）
  PR 画文字：PR <font> "<文本>" <x> <y> <rot> <sx> <sy> <r> <g> <b> <a>
      文本左上角在 (x,y)；font=字体资产号；rot sx sy 同 D
  R  画矩形：R <mode> <x> <y> <w> <h> <rx> <ry> <width> <r> <g> <b> <a>
      左上角 (x,y)、宽 w 高 h；rx ry=圆角半径（0=直角）；width=线宽
      （仅 mode 1 描边时有效，填充时写 1）
  LN 画折线：LN <点数N> <x1> <y1> ... <xN> <yN> <width> <r> <g> <b> <a>
      依次连接各点；width=线宽；两点即为线段
  PY 画多边形：PY <mode> <点数N> <x1> <y1> ... <xN> <yN> <r> <g> <b> <a>
      各顶点依次连成闭合图形；mode 0=实心 1=描边
  CI 画圆：CI <mode> <x> <y> <r> <seg> <r> <g> <b> <a>
      (x,y)=圆心，r=半径，seg=边数（越大越圆，常用 24~40）
  AR 画弧/扇形：AR <mode> <arctype> <x> <y> <r> <a1> <a2> <seg> <r> <g> <b> <a>
      圆心 (x,y)、半径 r；a1=起始角 a2=终止角（弧度！从正右方起顺时针）；
      arctype: 0=pie 扇形（两条半径+弧），1=open 纯弧线，2=closed 弧+弦闭合
  PT 画点：PT <点数N> <x1> <y1> ... <xN> <yN> <size> <r> <g> <b> <a>
      每个点画成 size 大小的方块（做星星/粒子）
  rt 切换画布：rt <目标canvas资产号|0=屏幕>
      之后所有行画到该画布上（先画完再 rt 0 回屏幕合成）
  SC 裁剪窗：SC <x> <y> <w> <h>
      之后只有该矩形区域内的绘制可见；恢复全屏=SC 0 0 <宽> <高>

变长行铁律（LN/PY/PT）：op 后紧跟点数 N（PY 在 mode 后），后跟恰好 N 对坐标，
最后是 width/size + 4 个色值。点数写错或坐标对不齐 = 整行被拒：
  LN 2 100 200 300 400 1 0 120 160 255              ← 2 点线段
  PY 0 3 100 240 180 160 260 240 100 100 120 255   ← 3 点三角形（0=填充）
  PT 1 320 240 3 255 255 255 255                    ← 1 个点（点数恒写 1）
圆与弧示例（CI 与 AR 参数表不同，勿混用；AR 的 a1/a2 是弧度不是度数）：
  CI 1 320 260 180 32 0 180 216 255                 ← 描边圆：圆心 半径 边数 色
  AR 0 0 320 260 180 0 0.5236 12 0 220 255 70      ← pie 扇形：从 0 到 0.5236 弧度（30°）

7. **CP 行（帧复制）**：`CP <ref>` = 本帧行集与帧 ref 完全相同；画面静止时
   写裸 `CP`（=上一帧）。CP 帧独占（帧内只有它）。
8. **对象编辑行**（作用于上一帧画面；**只能寻址 D 精灵行**）：
   `MOVE <资产> <dx> <dy>`   往哪挪多少（如 MOVE 1 4 0 = 右移 4）
   `PLACE <资产> <x> <y>`    放到哪（绝对坐标）
   `POSE <资产> "<新D行>"`   换形态/贴图/姿势（整行替换）
   `ENTER "<新行>"`          新对象入场（画在最上层）
   `EXIT <资产>`             对象离场
   同资产多实例时第 2 个起写 `MOVE <资产> 1 <dx> <dy>`（第 k 个实例）。
   编辑帧只写编辑行（clear 不用写）；多边形/线/圆等**矢量行的移动=整行重写**
   （PY/LN/CI/AR 不支持编辑行）。编辑帧不得与全量行混帧；frame 0 必须全量行。
9. **ev 事件行**（in 段；由 runner 书写并注入请求，你不书写 ev 行）：
   `ev <slot> "<type>" <src> <argc> <args...>`
   slot=事件序号（从 0 起）；src=来源（0=OS 真实输入，2=脚本合成）；
   argc=参数个数；args 按 type 的参数序写 variant 序列
   （num <数值> / str "<文本>" / bool 0|1）。常用 type 的参数序：
     mousepressed:  num <x>  num <y>  num <button>  num <istouch>
     mousereleased: num <x>  num <y>  num <button>  num <istouch>
     keypressed:    str <key>  num <isrepeat>
   流内时序：ev 行所在帧=事件发生帧（该帧行集照常书写），
   其后的帧=事件后的世界。
   示例（用户在 (320,300) 按下鼠标左键）：
     ev 0 "mousepressed" 0 4 num 320 num 300 num 1 num 0
10. **地牢房间模式**（world runner 专用）：
   你在构建无限地牢的一个房间（room），房间内容完全由你创作——主题、
   布局、生物、机关、什么行为得多少分，全部你定。硬规则：
   - 本房积分上限 100（HUD 用 PR 行实时显示积分与房间号）；
   - directive 给你"奖励拾取:遇怪"的目标比例，按此密度布置房间；
   - **通关信令**：玩家完成通关条件后，连续三帧每帧写一行字幕
     `PR 4 "pass=<本房实得积分>" 260 240 0 1 1 255 215 0 255`
     （三帧同值；runner 认到三连且 lint 通过才结算进入下一房间）；
   - **死亡信令**：玩家死亡后，先写 run 结算画面（总结本次表现：完成
     房间数/累积总分/亮点，用 PR 行展示数帧），随后连续三帧写
     `PR 4 "over=<累积总分>" 260 240 0 1 1 255 80 80 255`
     （run 就此终结，runner 保存流）；
   - 房间帧数上限到达仍未通关，runner 直接进入下一房间（本房 0 分）。
   玩家输入照常经 ev 到你；战斗、移动、拾取的表现方式全部你发挥。

**行走示例（匀速右移，每帧 MOVE 而非整帧重写）**：
frame 5
C 34 139 34 255
D 1 0 160 200 0 1 1
D 2 0 240 200 0 1 1
PR 4 "HEROES MARCH" 12 12 0 1 1 255 215 0 255
frame 6
MOVE 1 4 0
MOVE 2 4 0
（背景/文字不变就不再重写——只写变化的部分）

R 0 0 0 640 24 0 0 1 90 90 120 255
PR 2 "HP 87" 12 12 0 1 1 255 255 0 255
