# dream/vocab.txt —— LLM 书写 FR 的词汇速查（**:px 紧凑档**；真源 tables/cmd.tbl）
会话几何与资产目录单由系统消息给出；你只写 frame 块。规则：
1. 每块以 `frame N` 开头（N 从上一帧 +1 连续递增）；
2. 块内只写绘制行（短名）；dt/asset/ev/s_crc/d_crc 由 runner 书写，出现即拒绝；
3. 坐标/尺寸是整数时就写整数（100 而非 100.000000）；确有小数才写 %.6f；
   **角度一律弧度**（整圈=6.2832，90°=1.5708，30°=0.5236）；
4. 行序=深度：后写的行盖住先写的。全量帧固定顺序：clear 最先 → 背景行其次 →
   人物/物件再次 → 文字 print 最后；
5. 资产只引用目录单里的 id（fr-lint L001 拦截幻资产号）；
6. 运动=每帧重算坐标：抛物线 y=h-4t(T-t)、圆周 x=cx+r*cos(a) y=cy+r*sin(a)、
   帧动画=按 frame N 奇偶交替换图。三角函数值自己算好写进行里。

绘制行短名（mode: 0=填充 1=描边；arctype: 0=pie 1=open 2=closed）：
  C <r> <g> <b> <a>                         ← 清屏色（全量帧首行）
  D <tex> 0 <x> <y> <rot> <sx> <sy>         ← 位图精灵；第 2 参 0=整图不裁剪；
                                              尾部 ox oy 色 可省略（默认 0/白）
  PR <font> "<文本>" <x> <y> <rot> <sx> <sy> <r> <g> <b> <a>
  R <mode> <x> <y> <w> <h> <rx> <ry> <width> <r> <g> <b> <a>
  LN <点数N> <x1> <y1> ... <xN> <yN> <width> <r> <g> <b> <a>
  PY <mode> <点数N> <x1> <y1> ... <xN> <yN> <r> <g> <b> <a>
  CI <mode> <x> <y> <r> <seg> <r> <g> <b> <a>          ← seg=边数（如 32）
  AR <mode> <arctype> <x> <y> <r> <a1> <a2> <seg> <r> <g> <b> <a>
  PT <点数N> <x1> <y1> ... <xN> <yN> <size> <r> <g> <b> <a>
  rt <目标canvas资产号|0=屏幕>
  SC <x> <y> <w> <h>

变长行铁律（LN/PY/PT）：op 后紧跟点数 N（PY 在 mode 后），后跟恰好 N 对坐标，
最后是 width/size + 4 个色值。点数写错或坐标对不齐 = 整行被拒：
  LN 2 100 200 300 400 1 0 120 160 255              ← 2 点线段
  PY 0 3 100 240 180 160 260 240 100 100 120 255   ← 3 点三角形（0=填充）
  PT 1 320 240 3 255 255 255 255                    ← 1 个点（点数恒写 1）
圆与弧示例（CI 与 AR 参数表不同，勿混用；AR 的 a1/a2 是弧度不是度数）：
  CI 1 320 260 180 32 0 180 216 255                 ← 描边圆：x y r seg 色
  AR 0 0 320 260 180 0 0.5236 12 0 220 255 70      ← pie 扇形：从 0 到 0.5236 弧度（30°）

7. **CP 行（帧复制）**：`CP <ref>` = 本帧行集与帧 ref 完全相同；画面静止时
   写裸 `CP`（=上一帧）。CP 帧独占（帧内只有它）。
8. **对象编辑行**（作用于上一帧画面；**只能寻址 D 精灵行**）：
   `MOVE <资产> <dx> <dy>`   往哪挪多少（如 MOVE 1 4 0 = 右移 4）
   `PLACE <资产> <x> <y>`    放到哪（绝对坐标）
   `POSE <资产> "<新D行>"`   换形态/贴图/姿势（整行替换）
   `ENTER "<新行>"`          新对象入场（画在最上层）
   `EXIT <资产>`             对象离场
   同资产多实例时第 2 个起写 `MOVE <资产> 1 <dx> <dy>`（第 k 个实例）。
   编辑帧只写编辑行（clear 不用写）；多边形/线/圆等**矢量行的移动=整行重写**
   （PY/LN/CI/AR 不支持编辑行）。编辑帧不得与全量行混帧；frame 0 必须全量行。

**行走示例（匀速右移，每帧 MOVE 而非整帧重写）**：
frame 5
C 34 139 34 255
D 1 0 160 200 0 1 1
D 2 0 240 200 0 1 1
PR 4 "HEROES MARCH" 12 12 0 1 1 255 215 0 255
frame 6
MOVE 1 4 0
MOVE 2 4 0
（背景/文字不变就不再重写——只写变化的部分）

示例帧（几何 640x480；白方块+红字标题）：
frame 7
C 20 24 36 255
D 1 0 132 240 0 1 1
R 0 0 0 640 24 0 0 1 90 90 120 255
PR 2 "HP 87" 12 12 0 1 1 255 255 0 255
