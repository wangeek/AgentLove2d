# B14 紧凑编码批 实施计划（spec v1.3）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 人可读紧凑档（`:px`）落地——短名指令 + 默认值省略 + 整数像素量化，实测收益入 benchmarks；`:full` 档（现行 canonical）零扰动。

**Architecture:** 档位=文本渲染参数化（用户定调：类比模型量化精度）。opcode=表行序不变 ⇒ **.frb 二进制生态零破坏**；短名/省略只发生在 `:px` 档的文本渲染层。`short`/`default` 列进 cmd.tbl 但**不进 canonical 指纹**（渲染参数非语义——否则全部现存流头 sha 失效）。录制端默认 :full（判据生态零扰动），紧凑流由转换工具产出。

**设计真源:** docs/plans/2026-10-29-b13-entropy-roadmap-design.md §3 + 附录 §5.3/5.4。

**准入数据（B13 实测）:** 省略表=rot/ox/oy/color=white/width/rx/ry（双场景 1.00）；sx/sy 出局（battle 0.00）；px 模拟收益 -75%。

**短名映射（附录 5.3-⑤，SVG path 传统）:** draw→D rect→R clear→C print→PR line→LN circle→CI poly→PY arc→AR points→PT scissor→SC rt→RT（dt/ev/asset 段行 ≤3 字符合规不改）。
