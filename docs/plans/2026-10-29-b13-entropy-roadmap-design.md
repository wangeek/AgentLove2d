## 3. B14 轮廓（骨架先立，数据填肉，spec v1.3）

### 3.1 head 精度档语法（草案）

```
frb1 <w> <h> <sha> <loglvl> <seed> :<prec>
   :full = %.6f 全精度（现状判据锚；缺省=兼容，旧流零改动）
   :px   = 整数像素域（渲染等价：落屏本就整数）
   :q64  = 1/64 域（动画亚像素）
```

- 语义层恒定（op 集/字段含义/段结构不动）；档位只是数值编码参数化
- 读取端按档解码；.frb 侧各档自由选编码（varint 等）——文本/二进制同语义两编码（D10 同构）
- 跨档关系：full→px 单向量化（有损、渲染等价）；值落档内则双向无损

### 3.2 默认值省略规则（数据准入制）

- 默认值表进 cmd.tbl `default` 列——生成器单一真源纪律延续
- **准入门槛：B13 命中率 >90% 的参数才收**（B13 实测裁定：rot/ox/oy/color=white/width/rx/ry 双场景 1.00 准入；**sx/sy=1 被双场景锚纠偏出局**——battle 命中 0.00）
- 尾部省略（proto3 风格：后缀参数省略，中段不省——保无状态解析）
- color 高频白等 token 缩写由数据定
- **短名指令集并入本批**（附录 5.3-⑤：draw→D 等十一个短名映射，SVG path 单字母传统）

### 3.3 判据分层

| 层 | 判据 |
|---|---|
| 同档 round-trip | 逐字节相等（现行最高纪律不变） |
| 跨档归一 | 展开→full→字段级语义等价；渲染等价 = 各档锚各的 D_CRC golden（不跨档比 CRC——量化本就变字节） |

### 3.4 边界与不做

行模板/续行（跨行状态）不做——等 B13 剩余熵裁决；帧间增量（B15）不做；
**录制端默认输出 full 不变**（判据生态零扰动；紧凑档由工具/frb 产出——录制行为与流档位解耦）。

预估三天批次（spec v1.3 + 生成器双目标 + 判据分层 + golden 重锚）。

## 5. 附录（2026-10-29 第二轮讨论沉淀：时间轴、生成协议、DSL 参照——用户共创）

### 5.1 语义脏与事件驱动的增量结构（"结构免费送"的时间轴兑现）

- **语义脏 ≠ 几何脏**（用户洞见）：横版卷轴背景平移 = 像素全帧变动 / 行级一行变化 / **语义层仅 x 一个值**；sprite sheet 动画 = 视觉动作切换 / 数据仅**索引号 +1**。我们的 diff 粒度有四层，每层判据免费：
  `same`（idle 静止 ~30B）→ `rowdelta`（行集增删）→ `paramdelta`（行不变参数变，几字节）→（`loop` 降传输层，见 5.3）
- **ev 是冗余的免费标记**（AV1 没有的 luxury）：out 的变/不变由 in 段事件驱动（world_map 无事件帧 D_CRC 恒定实证）——same 判定从 O(行) 搜索降为 O(1) 事件谓词；delta 链边界 = 事件边界（一次点击后的动画段是一个"响应包"）；checkpoint 优先落事件边界（随机加入永远落在因果起点）。
- **流式最小解析单位是行**（用户定调）：增量帧不是帧级 diff 结构，是行级操作序列（到即解）；帧退回纯逻辑分组（checkpoint/校验和锚点）。

### 5.2 状态快照命题的关闭（用户裁定：序列化状态图是伪命题）

四场景状态角色重审：录制=观测（st/s_crc 是观测非快照）；回放=状态不存在（无视 ev，画面=f(out)）；sim=验证工具自建状态（非流消费需求）；**LLM dream=状态即流历史+LLM 上下文（无 handler——事件由 LLM 思考响应，不存在"恢复状态给内核"）**。结论：**流是唯一需要持久化的物**（WAL 主义到底）；序列化法无服务对象，正式出局；LLM 接续=读前缀流/投影摘要（消费端工具，类似 chat history 压缩），不进流格式。ev 行双生产者语义：录制流=内核输入事实 / dream 流=LLM 打断事实——同格式，消费端按需解释。

### 5.3 指令集设计纪律（CISC/RISC 之鉴，用户拍板）

1. **基座冻结、增量走扩展集**（RISC-V 模式）：现有 14 op 最小正交集封版即冻结；增量词汇是正交扩展集（版本声明+能力协商+可降级）。游戏模式不发明基座指令——卷轴 = draw+paramdelta 组合，零新指令（LLVM pattern 层同构）。
2. **幂等优先、增量归编码层**：paramdelta 文本形态绝对值（任意帧独立可解）；最紧凑表达由编码层做（相对+周期 checkpoint 回绝对）。
3. **loop 不进流语义**（用户裁定）：时间后向引用破坏可局部解码——降传输层优化（发送端展开 same 序列省带宽）或播放侧模式。
4. **五端养活门槛**：fr-gen 生成/回放器执行/fr-check 判据/LLM token 经济/人眼直读，五端同受益才转正；否则归 err 边界登记（escape 序列）。
5. **短名指令集**（用户定调，≤3 字符）：`draw→D`（最高频单字符）`rect→R` `clear→C` `print→PR` `circle→CI` `points→PT` `scissor→SC` `poly→PY` `arc→AR` `line→LN`；并入 B14（同属 canonical 演进，一次破版一次重锚）。
6. **fr-lint 三层**（AI 幻觉防线）：语法层（行格式/参数域）+语义层（引用完整性/帧号/end 配对——WASM 验证模型同构）+锚定回放层（D_CRC 终审）；输出编译器式诊断（行号+错误码+修复提示），LLM 生成→lint→打回→自助修复。
7. **跨帧行身份**：git diff 处刑（内容哈希恰在最需身份时失效）；采纳 **React key 模型**——身份显式声明不从内容推导：一级锚=资产 id（登记制唯一稳定），消歧后缀=帧内引用序 k（`(7,k)`）；身份是编码器可验证的优化非承诺——匹配失败（y-sort 重排）降级 rowdelta，损失压缩率不损失正确性。无资产行不建身份（YAGNI）。

### 5.4 DSL 参照原型（用户要求：不从零发明，每个语法件有部署背书）

| 参照 | 借什么 | 部署背书 |
|---|---|---|
| **SVG path data**（主参照） | 单字母指令；**隐式指令延续**（`L 300 400 500 600`=多段 L——行模板原型）；**大小写=绝对/相对双模式**（`L`/`l`——paramdelta 的 abs/rel 语法位，选择权给生产者） | 浏览器 20 年，人手写常见 |
| **汇编 section + JVM 常量池** | 段=伪指令（directive）vs 绘制行=指令的心智模型；资产表=常量池（索引引用符号表）；javap 显示形态=fr-dump 参照 | 史上最大部署规模 |
| **WAT/WASM + LLVM .ll/.bc** | 双形态 round-trip 语义等价；**WASM 验证模型**=fr-lint 语义层先例（非法模块拒载） | 标准化工业实践 |
| **Python dis** | 显示层符号注解（`0 (x)`）——源紧凑/显示加注分层 | — |

改写示例（draw 行按 SVG path 风格）：`D 7 0 100 200`（绝对）/ 行模板 `D 7 0 100 200 132 200 164 200`（坐标对隐式延续）/ 参数增量 `d 7 x=2`（小写=相对）。**不抄**：PostScript/PDF 后缀操作符（首 token 定分派对流式解析更友好）、WAT S 表达式（树形过度结构）。

### 5.5 B15/B18 设计输入的落点

- **B15（增量扩展集）**：四层词汇（same/rowdelta/paramdelta；loop 出局）按 5.3 纪律设计；词汇表最终形态等 B14 落地后以真实紧凑流为基座再定（用户明确不急）。
- **B18（dream 生成协议）**：部件=流+结算器+LLM+lint（无新底层机制）；唯一真设计点=**前缀投影格式**（LLM 接续的上下文摘要形态）；打断=分叉点标记+append 语义。
- **本设计不改动 B14 范围**：短名化并入 B14（5.3-⑤），其余均为 B15+ 素材。
