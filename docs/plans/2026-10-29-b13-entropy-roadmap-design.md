```

   │  时效性：canonical 越晚改越贵（golden/判据/示例全锚它）

   │  词汇表等 B14 落地——"与参考帧相同"是默认值省略在时间维的推广
   ▼
```

无实测不立项（B14 每条省略规则要命中率数据背书）；**② 双场景锚**——静态
（world_map）+ 动态（battle）两个基准流，任何优化双场景同时报数。

### 先例映射（设计语言的出处；"太阳底下没有新问题"）

| 本项目机制 | 先例 | 借鉴点 |
|---|---|---|
| 参数默认值省略 | proto3（默认值不编码） | 协议级省略原则；尾部省略保无状态 |
| 量化精度档 | 大模型量化档（FP32/INT8，用户类比）；ASN.1 PER | 值域从物理事实（像素）推出；档位是 head 参数 |
| 行模板/续行（缓） | MIDI running status；HTTP/2 HPACK 双字典 | 流式上下文省略；跨行状态是成本源（故缓行） |
| 帧间增量 | AV1：I/P 帧、SKIP、**参考帧池（ALTREF）**、tile 分块、film grain synthesis | 周期 checkpoint=关键帧；**分层参考**（图层各自最优参考帧）；**效果合成指令**（种子+规则替代逐帧编码）是 v2 词汇表构想 |
| 资产内容寻址 | git packfile / HTTP ETag | 跨会话去重 + 客户端缓存命中 |
| 结构优势 | —（先例皆无） | 视频编码从像素猜结构；符号流的结构（行号/资产号/图层）免费送 |

**双跑 D_CRC 序列一致**才算基准成立（与 world_map 锚同纪律）。预期动态熵
谱：单位移动、blend 拖尾粒子（battle.lua 实证 setBlendMode add 路径）、

### 2.2 fr-stats 工具（tools/fr_stats.py）

输入 .fr/.frb；输出文本报告 + `--json` 机读。四层剖面：

| 层 | 报告 | 回答 |
|---|---|---|
| op 层 | 每 op 行数/字节占比/均行长 | 压缩火力对准谁 |
| 参数层 | 每参数默认值命中率（rot=0/sx=1/color=255…）、重复率 | B14 省略表准入证据 |
| 量化层 | 模拟 px/q64/q16 编码字节（含省略叠加、参考 gzip） | 量化档收益上限 |
| 时间层 | 帧间整行重复率（same 帧占比）、行集 diff 分布 | B15 真实空间；静态 vs 动态锚对比 |

工具自身进回归（golden 流剖面锚——数字漂移 = 行为报警）。

## 3. B14 轮廓（骨架先立，数据填肉，spec v1.3）

### 3.1 head 精度档语法（草案）

```
frb1 <w> <h> <sha> <loglvl> <seed> :<prec>
   :full = %.6f 全精度（现状判据锚；缺省=兼容，旧流零改动）
   :px   = 整数像素域（渲染等价：落屏本就整数）
   :q64  = 1/64 域（动画亚像素）
```

- 语义层恒定（op 集/字段含义/段结构不动）；档位只是数值编码参数化
- 读取端按档解码；.frb 侧各档自由选编码（varint 等）——文本/二进制同语义两编码（D10 同构）
- 跨档关系：full→px 单向量化（有损、渲染等价）；值落档内则双向无损

### 3.2 默认值省略规则（数据准入制）

- 默认值表进 cmd.tbl `default` 列——生成器单一真源纪律延续
- **准入门槛：B13 命中率 >90% 的参数才收**
- 尾部省略（proto3 风格：后缀参数省略，中段不省——保无状态解析）
- color 高频白等 token 缩写由数据定

### 3.3 判据分层

| 层 | 判据 |
|---|---|
| 同档 round-trip | 逐字节相等（现行最高纪律不变） |
| 跨档归一 | 展开→full→字段级语义等价；渲染等价 = 各档锚各的 D_CRC golden（不跨档比 CRC——量化本就变字节） |

### 3.4 边界与不做

行模板/续行（跨行状态）不做——等 B13 剩余熵裁决；帧间增量（B15）不做；
**录制端默认输出 full 不变**（判据生态零扰动；紧凑档由工具/frb 产出——录制行为与流档位解耦）。

预估三天批次（spec v1.3 + 生成器双目标 + 判据分层 + golden 重锚）。
