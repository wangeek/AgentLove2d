# B4-2 里程碑二：捕获层接入 fork（capture-then-replay 首帧上屏）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 魔改第一批——把 FR 捕获/回放接进 fork：`FR_CAPTURE=1` 时 `love.graphics.*` 只记录不执行，present 前由 C 回放器执行记录行，**屏幕显示的是回放结果**（视觉真源=IR），并把当帧会话写为 `.fr` 文本（tee₁）。

**Architecture:** 捕获层落在 **fork 工作树 = `megasource/libs/love`**（其自身是 git 仓库 6eb8d54——魔改提交在 fork 仓库内做，魔改前先建 fork 侧分支基线）。行级编解码文件由 gen_c 生成后拷入 fork（`src/modules/graphics/fr/`），不手改；捕获钩与回放器为手写 C++（`fr_capture.cpp/.h`，挂 wrap_Graphics.cpp 的 w_* 边界）。开关用环境变量 `FR_CAPTURE`（零侵入默认路径）。

**Tech Stack:** C++（love 11.5 代码基）+ CMake（libs/love 目标）+ 本机 MSVC/mingw64 双编译器验证。

**依据：** design.md §6 B4-2 行（验收线：capture-then-replay 首帧上屏；拓扑 B 离线回放 d_crc 一致）；D8（捕获边界/语义替代/两段式）；love2d-gap.md §二（捕获后回放、变换栈就地结算）。

**集成点锚（fork 实测）**：`libs/love/CMakeLists.txt:282` 起源文件清单；`wrap_Graphics.cpp` w_clear:73 / w_present:181 / 注册表:2912-2914；run loop 替换走 demo kernel 的 main.lua 自定义 `love.run`（不改 callbacks.lua）。

**关键设计决策（实现者按此执行，细节自定）**：
1. **捕获形态**：C++ 侧直接产 **.fr 行文本**（与 L0 同构——文本判据链已全通；二进制 tee 归后续）。行缓冲 = `std::vector<std::string>`，present 钩消费。
2. **抑制语义**：捕获开启时 w_draw/w_print/w_rectangle/w_clear **只记录**；clear 的抑制需记录颜色供回放重绘（clear 是状态清除，回放时重执行）。
3. **回放执行**：present 钩（w_present 或 graphics->present 前的自定义函数）遍历行缓冲 → 调用 Graphics::draw/print/rectangle/clear 的 C++ 接口（与 w_* 同一 instance()-> 方法，绕过 Lua 边界）→ 屏幕显示回放帧。
4. **语义替代四件套**：newImage/newFont/newCanvas/newQuad → 资产注册（自增 id + CPU 字节登记），返回**资产代理 userdata**（携带 id）；draw 首参解析代理取 id。L0 的 data_hex 假数据模式保留（L0 无真解码——代理不建真纹理；draw 回放时按 id 查 CPU 字节经 ImageData 物化——**若物化成本高，demo 期可先用纯色矩形占位代理渲染**，如实标注）。
5. **变换栈**：捕获坐标 = 用 `Graphics::getTransform()` 当前矩阵结算（等价 L0 的 shim 栈，但用 love 自己的变换——更忠实）。
6. **tee₁**：demo kernel 的 main.lua 在会话结束时经新增 C 函数 `love.graphics._frTakeSession()` 取全部行文本 → 组装 .fr（复用 L0 的会话组装逻辑）→ 写文件。
