# B4 阶段三：真纹理物化 + 拓扑 B 离线回放 + d_crc + null Graphics

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 补完 B4-2 验收线第二分句——同流文件经拓扑 B 离线回放（.frb → C 解码 → 真渲染），并与同进程回放（tee₂）d_crc 一致。同时把语义替代从"假数据占位"升级为"真字节物化"（ImageData → uploadImageData），交付 null Graphics 无头拓扑。

**Architecture:** 四个交付物按依赖序推进：①语义替代登记真字节（newImage(ImageData) 路径把 ImageData 的 RGBA 字节 hex 化登记，newFont 登记真 TTF/位图字节）→ ②真纹理物化器（replay 时按 id 查 CPU 字节 → love::image::ImageData 构造 → gfx->newImage → 真纹理 draw）→ ③拓扑 B 离线回放 CLI（fr-render：读 .frb/.fr → C 会话解包 → 行解码 → 驱动 fork love.exe 内嵌回放器 → Canvas 回读 → d_crc 输出）→ ④null Graphics（FR_CAPTURE=1 + FR_HEADLESS=1：Graphics 模块挂空实现，不创建窗口，tee₂ 跳过）。d_crc 采集点 = 离线回放器 Canvas 回读后 CRC32（与 L0 walker 同多项式）。

**Tech Stack:** fork C++（MSVC/mingw64 双编译器）+ Python CLI 驱动 + 既有 fr_codec/fr_session。

**依据：** design.md §6 B4-2 第二分句 + 阶段三就绪度评估；fr_capture.h 头注（真纹理物化归阶段三、转义反转义未实现清单）；B4-1 交付的 C 解码（fr_dec_*）与会话层（fr_session_*）。

**关键 API 锚（侦察实测）**：
- 真纹理物化：`Graphics::newImage(const Image::Slices &data, const Image::Settings &settings)`（Graphics.h:474）——Slices 从 `love::image::ImageData` 构造（fork 源码中 w_newImage 的 ImageData 路径即此）
- 字体：`Graphics::newFont(love::font::Rasterizer *data, ...)`（Graphics.h:478）——Rasterizer 从 `love::font::TrueTypeRasterizer`/`newTrueTypeRasterizer(Data*, size)` 构造
- draw 直调已有（capture_replay 在用）；Canvas 回读（_frNewCanvasReal + newImageData）Task 2 已实证
